# SHIPMATE AI

조선업의 복잡한 설계 검토와 인력 배치 의사결정을 한 화면에서 지원하는 프론트엔드 UI 프로토타입입니다. 선박 도면의 설계·법규 사전 검토와 조선소 직원의 역량 기반 배치 추천 흐름을 심사위원에게 시연할 수 있도록 구성했습니다.

## 해결하려는 문제

- 여러 도면과 검토 기준에 흩어진 설계 리스크를 빠르게 파악하기 어렵습니다.
- 프로젝트별 필요 역량과 직원의 경험·업무량을 함께 비교하기 어렵습니다.
- 분석 결과가 있어도 의사결정자가 이해할 수 있는 설명과 근거가 부족합니다.

## 핵심 기능

1. **선박 설계·법규 검토 지원**: 프로젝트 등록, 도면 선택, mock 분석 진행, 조건부 적합 결과와 수정 권고를 제공합니다.
2. **조선소 인력 배치 지원**: 직원 역량 검색·필터·상세 확인, 업무별 사전 계산 적합도 및 추천 근거를 제공합니다.

## 기술 스택

- Next.js App Router, React, TypeScript
- Tailwind CSS 기반 빌드 환경 + 프로젝트 전용 반응형 CSS
- Lucide React 아이콘

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 타입 검사, 린트, 프로덕션 빌드는 각각 아래 명령을 사용합니다.

```bash
npm run typecheck
npm run lint
npm run build
```

## 환경변수와 API 보안

`.env.example`을 복사해 `.env.local`을 만들 수 있습니다. 현재 프로토타입은 API 키를 사용하지 않습니다.

```env
OPENAI_API_KEY=
```

`.env.local`은 `.gitignore`의 `.env*` 규칙으로 Git에서 제외됩니다. `NEXT_PUBLIC_OPENAI_API_KEY`는 사용하지 않으며, 향후 OpenAI 연동도 브라우저가 아닌 Next.js Route Handler 또는 서버 함수에서만 수행합니다.

## 현재 데이터와 향후 연동

현재 모든 프로젝트, 검토 결과, 직원 및 추천 결과는 `lib/mock-data`의 가상 데이터입니다. 파일은 실제 서버에 업로드되지 않고, 분석 과정도 UI 시연용 상태 전환입니다. 관련 규정 표기는 실제 규정을 단정하지 않는 **시연용 예시 데이터**입니다.

향후에는 서버 전용 분석 엔드포인트에서 도면 정보 추출 AI를 호출하고, 별도 법규 데이터 및 결정론적 검증 로직으로 판정을 수행합니다. 인력 적합도와 순위 역시 코드와 검증된 인사 데이터가 계산합니다. AI는 이미 계산·판정된 근거를 이해하기 쉬운 문장으로 설명할 뿐, 실제 점수·규정 판정·최종 인사 결정을 담당하지 않습니다.

# 작업자 제약조건 (Worker Constraints)

## 1. 목적

본 문서는 선박 조립 공정의 작업자 자동 배정을 위한 작업자 제약조건을 정의한다.

본 프로젝트의 1차 MVP에서는 다음 4가지 작업자 유형을 대상으로 한다.

- 취부공
- 용접공
- 사상공
- 품질검사원

본 제약조건은 Genetic Algorithm(GA)을 이용한 작업자 자동 배정 및 스케줄링 과정에서 사용된다.

---

## 2. 작업자 유형

| 작업자 유형 | 주요 작업 |
|---|---|
| 취부공 | 부재 위치 조정, 가접, 조립 및 정렬 |
| 용접공 | 부재 및 블록 용접 |
| 사상공 | 용접부 그라인딩, 표면 정리 및 마감 |
| 품질검사원 | 치수, 외관 및 용접 상태 검사 |

---

## 3. 작업 공정

1차 MVP에서는 기본적인 작업 순서를 다음과 같이 정의한다.

```text
취부 → 용접 → 사상 → 품질검사

각 작업은 선행 작업이 완료된 이후 다음 작업을 수행할 수 있다.

예:
취부 작업 완료
      ↓
용접 작업
      ↓
사상 작업
      ↓
품질검사

---

## 4. 작업자 데이터

각 작업자는 다음과 같은 정보를 가진다.

항목	설명
worker_id	작업자 고유 ID
worker_type	작업자 유형
skill_level	숙련도
available_start	작업 가능 시작 시간
available_end	작업 가능 종료 시간
availability	작업 가능 여부

예시:

worker_id	worker_type	skill_level	available_start	available_end
W001	취부공	3	08:00	17:00
W002	용접공	4	08:00	17:00
W003	사상공	2	08:00	17:00
W004	품질검사원	3	09:00	18:00

---

## 5. 작업자 제약조건

5.1 작업자 유형 제약

작업에 필요한 작업자 유형과 실제 작업자의 유형이 일치해야 한다.

예:

용접 작업 → 용접공
사상 작업 → 사상공
품질검사 → 품질검사원

따라서 용접 작업에 취부공을 배정할 수 없다.

5.2 필요 인원 제약

각 작업은 작업 수행에 필요한 최소 작업자 수를 가진다.

예:

취부 작업 → 2명
용접 작업 → 2명
사상 작업 → 1명
품질검사 → 1명

작업에 필요한 인원보다 적은 작업자가 배정되면 해당 해는 제약조건을 위반한 것으로 판단한다.

5.3 작업 가능 시간 제약

작업자는 본인의 작업 가능 시간 내에서만 작업할 수 있다.

예:

작업자 근무시간: 08:00 ~ 17:00
작업시간: 09:00 ~ 12:00

→ 배정 가능

반면,

작업자 근무시간: 08:00 ~ 17:00
작업시간: 16:00 ~ 18:00

→ 배정 불가능

5.4 작업 중복 제약

하나의 작업자는 동일한 시간에 여러 작업을 수행할 수 없다.

예:

W001

09:00 ~ 11:00  작업 A
10:00 ~ 12:00  작업 B

위와 같이 작업 시간이 겹치는 경우 제약조건 위반으로 판단한다.

5.5 숙련도 제약

각 작업은 최소 요구 숙련도를 가질 수 있다.

예:

작업 요구 숙련도 = 3
작업자 숙련도 = 2

→ 배정 불가능

작업 요구 숙련도 = 3
작업자 숙련도 = 4

→ 배정 가능

5.6 작업 선후관계 제약

작업 간 선후관계를 고려한다.

기본 공정은 다음과 같다.

취부 → 용접 → 사상 → 품질검사

따라서 용접 작업은 취부 작업이 완료된 이후 시작해야 한다.

사상 작업은 용접 작업이 완료된 이후 시작해야 하며, 품질검사는 사상 작업 이후 수행한다.

---

## 6. 제약조건 정리
제약조건	설명	위반 여부
작업자 유형	작업에 적합한 작업자 유형인지 확인	Hard Constraint
필요 인원	필요한 작업자 수를 충족하는지 확인	Hard Constraint
작업 가능 시간	작업자의 근무시간 내 작업인지 확인	Hard Constraint
작업 중복	동일 작업자의 작업시간이 겹치는지 확인	Hard Constraint
숙련도	작업 요구 숙련도를 만족하는지 확인	Hard Constraint
작업 선후관계	선행 작업 완료 후 작업이 시작되는지 확인	Hard Constraint

---

## 7. GA 적용 방식

Genetic Algorithm에서는 하나의 해(solution)가 작업자 배정 결과를 나타낸다.

예:

Task 01 → W001, W005
Task 02 → W002, W006
Task 03 → W003
Task 04 → W004

각 해에 대해 제약조건을 검사한다.

작업자 유형 확인
        ↓
필요 인원 확인
        ↓
작업 가능 시간 확인
        ↓
작업 중복 확인
        ↓
숙련도 확인
        ↓
작업 선후관계 확인
        ↓
Fitness 계산

제약조건을 위반한 해에는 페널티를 적용하거나 해당 해를 부적합 해로 처리한다.

# 섹터별 가동현황 연동 설계

## 원칙

이 서비스는 개인 근태나 감시 데이터를 받지 않는다. 사내 HR/근태 시스템이
사업장·작업일·섹터 기준으로 집계한 가용 인원만 읽는다.

```text
개인 근태 이벤트 → HR 내부 집계 → 섹터별 가동현황 API → 생산계획 서비스
```

서비스가 받는 최소 정보는 `sector_id`, `planned_headcount`,
`available_headcount`, `work_date`다. 사번·성명·출입시각·평가·영상 정보는
전달 대상이 아니다.

## 재최적화 기준

1. 섹터별 가용 인원 변동을 감지한다.
2. 변경된 섹터의 생산능력만 갱신한다.
3. 고정 섹터를 유지한 상태로 작업 순서와 섹터 내부 투입 인원을 재계산한다.
4. 공기 영향과 병목을 보여 주고, 현장 책임자의 승인 뒤 작업지시표를 MES에 전달한다.

## 데모와 운영 차이

데모에서는 `scripts/04_generate_sector_availability.py`와 대시보드 슬라이더가
집계 인원 변동을 모사한다. 운영에서는 해당 부분만 HR 집계 API 호출로 교체한다.
개별 태그를 읽거나 개인별 상태를 표시하는 기능은 의도적으로 포함하지 않는다.

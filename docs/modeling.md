# 수리 모델링 상세

## 1. 기호

| 기호 | 의미 |
|---|---|
| $B$ | 블록 집합, $b \in B$ |
| $P$ | 공정 집합 (절단, 취부, 용접, 사상) |
| $J$ | 작업 집합, $j = (b, p)$ |
| $W$ | 작업자 집합, $\|W\| = 50$ |
| $Z$ | 조립장 구역 집합 |
| $s_j, e_j$ | 작업 $j$ 의 착수·완료 시점 (가동 분) |
| $d_j$ | 작업 $j$ 의 소요시간 |
| $n_j$ | 작업 $j$ 의 투입 인원 수 |
| $C_j \subseteq W$ | 작업 $j$ 에 배정된 작업자 집합 |
| $\Gamma_j$ | 작업 $j$ 의 선행 작업 집합 |
| $D_b$ | 블록 $b$ 의 납기 |
| $\kappa$ | 구역당 동시 진입 한도 (3) |

## 2. 공수 산출식

블록 $b$ 의 표준 공수 $M_b$ 는 물량 항의 합에 곡면 보정과 선종 난이도를 곱한 값이다.

$$
M_b = \Big[ L_b \cdot \alpha_w \cdot \Big(\frac{g_b}{g_0}\Big)^{1.6} + N_b \cdot \alpha_f + W_b \cdot \alpha_h \Big] \cdot (1 + \beta \gamma_b) \cdot \delta_b
$$

| 항 | 의미 | 기본값 |
|---|---|---|
| $L_b$ | 총 용접 길이 (m) | - |
| $\alpha_w$ | 용접 원단위 (공수/m, 각장 6 mm 기준) | 0.20 |
| $g_b, g_0$ | 각장, 기준 각장 (mm) | -, 6.0 |
| $N_b$ | 부재 개수 | - |
| $\alpha_f$ | 부재당 취부 공수 | 0.35 |
| $W_b$ | 블록 중량 (ton) | - |
| $\alpha_h$ | 톤당 취급 공수 | 0.45 |
| $\beta$ | 곡면 페널티 | 0.60 |
| $\gamma_b$ | 곡면 부재 비율 | 0~1 |
| $\delta_b$ | 선종·형상 난이도 | 0.7~1.9 |

각장 지수 1.6 은 용착금속량이 각장의 제곱에 비례한다는 이론값(2.0)에서 자세·개선
조건에 따른 실무 보정을 뺀 값이다. 공정별 배분은 절단 0.12 / 취부 0.28 / 용접 0.45 /
사상 0.15 다.

## 3. 소요시간

인원을 늘리면 공수는 나뉘지만 간섭과 대기로 효율이 떨어진다.

$$
\eta(n) = \max(0.45,\ 1 - 0.08(n-1)), \qquad
d_j = \frac{M_j \cdot \sigma(C_j)}{n_j \cdot \eta(n_j)} \times 60
$$

$\sigma(C_j)$ 는 배정 작업자의 숙련도 계수 평균이다 (초급 1.35, 중급 1.00, 고급 0.82).

$\eta$ 의 형태 때문에 인원을 최대로 투입하는 것이 항상 유리하지 않다. 인원 6명에서
$n\eta = 3.60$, 8명에서 $3.52$ 로 오히려 나빠진다. 이 비단조성이 GA 가 탐색해야 할
실제 결정 공간을 만든다.

## 4. 목적 함수

최소화 대상은 정규화된 가중합이다. $R$ 은 기준 공기(5절).

$$
\min\ \ w_1 \frac{C_{\max}}{R}
+ w_2 \frac{I}{R\,|W|}
+ w_3 \frac{\text{sd}(u_w)}{R}
+ w_4 \frac{\sum_b T_b}{R\,|B|}
+ w_5 V
$$

| 항 | 정의 | 기본 가중치 |
|---|---|---|
| $C_{\max}$ | 최대 완료 시간 $\max_j e_j$ | 1.00 |
| $I$ | 유휴 시간 $\sum_w (\text{마지막 완료}_w - u_w)$ | 0.35 |
| $\text{sd}(u_w)$ | 작업자 누적 작업시간의 표준편차 | 0.25 |
| $T_b$ | 납기 지연 $\max(0, e_b - D_b)$ | 1.50 |
| $V$ | 숙련도 제약 위반 건수 | 5.00 |

## 5. 제약 조건

$$
\begin{aligned}
&\text{(C1) 선행 공정} & s_j &\ge \max_{k \in \Gamma_j} e_k \\
&\text{(C2) 자원} & &\forall w,\ \{[s_j, e_j) : w \in C_j\} \text{ 는 서로소} \\
&\text{(C3) 숙련도} & &\delta_b \ge 1.15,\ p \in \{\text{취부}, \text{용접}\} \Rightarrow |\{w \in C_j : \text{고급} \wedge \text{유자격}\}| \ge 1 \\
&\text{(C4) 공간} & &\forall z \in Z,\ \forall t,\ |\{b : \text{zone}_b = z,\ s_b \le t < e_b\}| \le \kappa \\
&\text{(C5) 중량물} & W_b \ge 20 &\Rightarrow n_j \ge 2 \\
&\text{(C6) 인원 범위} & &n^{\min}_p \le n_j \le n^{\max}_p
\end{aligned}
$$

C1~C6 은 모두 디코더가 구성 단계에서 강제한다. 페널티로 사후 처벌하는 방식이 아니므로
탐색 공간에 실행 불가능해가 존재하지 않는다. 예외는 C3 으로, 유자격 인력 자체가
고갈된 경우에만 위반을 허용하고 $V$ 로 계상한다. 인력 부족을 스케줄링으로 해결할 수
없다는 사실 자체가 출력되어야 할 정보이기 때문이다.

## 6. 기준 공기와 점수

두 가지 기준을 함께 계산한다.

$$
R_{\text{hard}} = \max\Big( \text{CP}(d^{\max\text{crew}}),\ \frac{\sum_j d_j n_j}{|W|} \Big), \qquad
R = \max\Big( \text{CP}(d^{\text{std}}),\ \frac{\sum_j d_j n_j}{|W|} \Big)
$$

$R_{\text{hard}}$ 는 모든 작업이 최대 인원을 독점한다고 가정한 엄밀한 하한이라
도달할 수 없다. 점수 분모로는 표준 인원 기준 임계경로 $R$ 을 쓴다.

$$
S = 100\Big( 0.45 \min\big(1, \tfrac{R}{C_{\max}}\big) + 0.15\,\rho + 0.15\,\beta_{\text{bal}} + 0.25\,\pi \Big) - 5V
$$

$\rho$ 는 가동률 $\sum_w u_w / (C_{\max}|W|)$, $\beta_{\text{bal}} = 1 - \text{sd}(u_w)/\bar{u}$,
$\pi$ 는 납기 준수 블록 비율이다.

## 7. 납기 설정

납기를 고정 지평으로 잡으면 문제 규모가 바뀔 때마다 전부 불가능하거나 전부 널널해져
지표가 의미를 잃는다. 블록별 임계경로 $\text{CP}_b$ 를 기준으로 설정한다.

$$
D_b = \max\Big( 1.15\,\text{CP}_b,\ R \cdot \big(0.60 + 0.70 \tfrac{r_b}{|B|}\big) \Big)
$$

$r_b$ 는 임계경로 오름차순 순위다. 첫 항은 물리적으로 불가능한 납기를 배제하고,
둘째 항은 기준 공기의 60~130% 구간에 납기를 분산시킨다.

## 8. 유전 알고리즘

| 요소 | 방식 |
|---|---|
| 인코딩 | 랜덤키 $priority \in [0,1]^J$ + $crew \in \mathbb{Z}^J$ + $mix \in \{0,1,2\}^J$ |
| 디코딩 | 직렬 스케줄 생성 (ready 집합에서 우선순위 최대 작업 선택) |
| 초기 세대 | SPT / LPT / EDD 휴리스틱 시드 3개 + 무작위 |
| 선발 | 상위 $selection\_size$ 개체로 번식 풀 구성 후 토너먼트 ($k=3$) |
| 엘리트 | 상위 $elite\_size$ 개체 무조건 보존 |
| 교차 | 우선순위 BLX-$\alpha$ ($\alpha = 0.25$), 인원·편성 균등 교차 |
| 돌연변이 | 우선순위 재추첨, 인원 $\pm 1$, 편성 재추첨, 블록 단위 통째 이동 |
| 종료 | 최대 세대 도달, 5분 경과, 또는 25세대 무개선 |

블록 단위 통째 이동 돌연변이는 국소 교란만으로 빠져나오지 못하는 배치를 흔들기 위한
것이다. 한 블록의 모든 공정 우선순위를 동일한 새 값으로 덮어써서 그 블록의 착수
시점을 통째로 옮긴다.

## 9. 계산 복잡도

디코딩 1회는 $O(J^2 + J|W|)$ 다. ready 집합 선형 탐색이 $O(J^2)$, 인원 선발이
`np.argpartition` 으로 작업당 $O(|W|)$ 다. 작업 120건, 작업자 50명 기준 디코딩 1회가
약 4 ms 이고, 개체군 300 기준 세대당 1.2초가 든다. 실측은 58세대 조기 종료로 75초였다.
전체 세대(80)를 다 돌아도 100초 수준이라 5분 제한 안에 들어온다.

세대마다 전체 개체군을 다시 디코딩한다. 엘리트는 유전자가 변하지 않으므로 비용을
캐싱하면 약 10% 를 줄일 수 있으나, 목적함수 가중치를 대시보드에서 바꾸는 경우
캐시 무효화를 다뤄야 해서 현재는 매번 재평가한다.

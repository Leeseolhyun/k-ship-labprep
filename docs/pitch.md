# 서류 심사용 정리

## Why — 배경

숙련공 감소와 신규 인력 유입으로 스테이션별 공수 편차가 커졌다. 계획 공수가 틀리면
후속 조립과 도크 탑재까지 지연이 연쇄된다. 지연의 원인은 두 단계로 나뉜다.

1. 예측 단계: 표준 원단위 계산이 숙련도 편차와 곡면·각장 같은 물량 특성을 반영하지 못한다.
2. 배정 단계: 작업자 50명을 블록에 배정하는 조합은 완전 탐색이 불가능하고,
   현장은 결국 경험칙과 엑셀로 익일 지시표를 만든다.

두 단계를 따로 풀면 의미가 없다. 예측이 정확해도 배정이 나쁘면 지연되고,
배정 알고리즘이 좋아도 입력 공수가 틀리면 최적화 대상 자체가 틀린 값이 된다.

## What — 핵심 기능

### 1. 예측: 공정별 소요 시간과 병목 사전 진단

블록 설계 스펙과 투입 인원 구성을 입력하면 공정별 공수를 예측한다.
표준 원단위 계산 대비 MAPE 16.4% → 12.2%.

SHAP 기여도를 공수 증가율로 환산해 원인을 문장으로 출력한다.
"B075 용접 — 계획 대비 54 MH 초과, 숙련도 계수 +10%, 용접 길이 +4%" 형태다.
숫자만 던지지 않고 어느 변수가 그 숫자를 만들었는지 함께 낸다.

### 2. 최적화: 4대 제약 하의 작업자 동적 배정

유전 알고리즘으로 우선순위·투입 인원·숙련도 편성을 동시에 진화시킨다.
제약은 페널티가 아니라 디코더 구성 단계에서 강제하므로, 출력되는 스케줄은 항상
실행 가능하다. 검증 테스트 9건이 제약 준수를 원자료에서 재검산한다.

규칙기반 대비 공기 27.9% 단축, 유휴 시간 42.3% 감소, 법령·선급규칙 위반 0건.
소요 시간 75초.

### 3. 시뮬레이션: What-If 분석

가용 작업자 수를 바꿔 가며 재최적화하고, 공기 단축 폭과 인건비 지수를 나란히 낸다.
"인원 10명을 더 넣으면 공기가 며칠 줄고 인건비는 얼마나 느는가" 에 숫자로 답한다.

### 4. 준법 점검

근로기준법·산업안전보건기준·한국선급 규칙을 정량 파라미터로 환산해 하드 제약으로 넣고,
확정 스케줄을 조항 ID 단위로 역검사한다. 위반이 나오면 어느 조항 때문인지 표시된다.

## Impact — 기대 효과

| 항목 | 근거 |
|---|---|
| 공정 계획 수립 시간 반나절 → 2분 | 실측 75초, 5분 제한 내 수렴 |
| 라인 유휴 시간 42% 감소 | 규칙기반 9,213h → GA 5,317h |
| 총 공기 28% 단축 | 32.9일 → 23.7일 |
| 공수 예측 오차 26% 개선 | MAPE 16.4% → 12.2% |
| 준법 리스크 사전 차단 | 확정 전 조항 단위 자동 점검 |

## 데이터 확보 전략

조선소 실적 데이터는 대외비다. 난수 생성 대신 물리 기반 합성 데이터를 택했다.
공수 산출식(용접 원단위, 각장 지수, 곡면 보정, 병렬 효율 감소)을 코드에 명시하고
그 위에 숙련도 편차와 로그정규 잡음을 얹었다. 결정론적 신호가 실재하므로 모델이
학습할 대상이 있고, 동시에 어떤 가정으로 만든 데이터인지 심사에서 그대로 열어 보일 수 있다.

`src/knowledge/drawing_spec.py` 가 CAD/BOM 추출물을 동일 스키마로 정규화한다.
실데이터가 확보되면 입력 경로만 교체되고 이후 파이프라인은 그대로 동작한다.

## 시연 시나리오 (5분)

1. 대시보드 실행, 블록 30개 · 작업자 50명 시나리오 로드 (30초)
2. 공수 예측 탭 — 병목 후보와 SHAP 원인 확인 (1분)
3. 스케줄 최적화 실행 — 수렴 곡선이 실시간으로 그려지는 동안 설명 (1분 30초)
4. 간트차트와 부하율, 규칙기반 대비 지표 비교 (1분)
5. What-If — 작업자 10명 추가 시 공기·인건비 변화 (1분)
6. 준법 점검 탭 — 위반 0건 확인 (30초)

## 발표 시 주의

종합 점수는 74.7점이다. 90점대를 주장하려면 점수 분모를 비교군으로 바꾸면 되지만,
그건 지표를 좋아 보이게 만드는 것이지 스케줄이 좋아지는 게 아니다.
질문이 들어올 지점이므로 "규칙기반 대비 공기 27.9% 단축" 을 전면에 세우고,
점수 정의(분모 = 표준 인원 기준 임계경로)를 먼저 밝히는 편이 방어에 유리하다.
